# 大数据与人工智能 课程仓库

> 本仓库用于记录与整理「大数据与人工智能」课程的学习内容、作业与实践项目。

## 📁 目录结构

| 目录 | 用途 |
|------|------|
| `notes/` | 课程笔记与知识点整理 |
| `assignments/` | 课堂作业与实验报告 |
| `projects/` | 综合项目与课程设计 |
| `data/` | 课程使用/练习的数据集 |
| `references/` | 参考资料与延伸阅读 |

## 🚀 快速开始

本项目使用 **Python 3.12** 作为主要开发语言，配合 Jupyter / VS Code 进行数据科学与机器学习实践。

### 环境要求
- Python 3.12+
- Git
- VS Code（建议安装 Python、Jupyter 扩展）
