- ★ 识记（约 30%）

## 使用建议

1. **先学后练**：建议先阅读 `notes/` 下对应的学习资料，再做题
2. **闭卷自测**：先独立完成题目，**不要提前翻看答案区**
3. **重做错题**：对照解析理解错因，并回到学习资料对应章节复习
4. **查漏补缺**：通过文末的"知识点分布表"定位薄弱章节
