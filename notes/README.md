# 学习资料索引

本目录收录由 `concept-learning-material` Skill 生成的概念学习资料。

## 资料列表

| 概念 | 文件 | 一句话概括 |
|------|------|-----------|
| **Agent（智能体）** | [Agent.md](./Agent.md) | 能自主规划、调用工具并根据反馈调整行动的 AI 系统 |
| **大模型的上下文** | [大模型的上下文.md](./大模型的上下文.md) | 模型本次推理能"看到"的全部输入信息，决定它此刻知道什么 |
| **Skill（技能）** | [Skill.md](./Skill.md) | 打包好的、可被 AI 按需加载的专业能力模块 |

## 三个概念的关系

这三个概念不是孤立的，它们共同构成"AI 如何可靠地完成复杂任务"的图景：

```
上下文  ← 决定模型每次能看到什么（认知边界）
   ↑
   | 按需注入
   |
Skill   ← 固化专业流程，节省上下文、稳定输出质量
   ↑
   | 被加载
   |
Agent   ← 执行主体，自主规划并调度工具与 Skill
```

- **Agent** 是"做事的主体"，它需要专业能力才能办好专业的事
- **Skill** 是 Agent 可以加载的"专业能力包"，其渐进式加载设计正是为了节省**上下文**
- **上下文** 是模型每次推理的认知边界，前两者的价值最终都体现在"如何用好上下文"上

## 阅读建议

- 初学者建议按 **上下文 → Skill → Agent** 的顺序阅读：先理解模型的认知边界，再看能力如何封装，最后看主体如何调度
- 每篇资料末尾的"延伸学习"列出了下一步方向
