# 题库设计指南

## 一、题型详解与示例

### 单选题 `[单选]`
考查单一知识点，四个选项，仅一个正确。

```
**1.** Agent 与工作流（Workflow）最本质的区别是什么？
A. Agent 运行速度更快
B. Agent 的步骤在运行时自主决定，工作流的路径预先固定
C. Agent 一定能联网，工作流不能
D. Agent 不需要大模型，工作流需要
```
**设计要点**：干扰项应来自真实误区（如 D 项来自"Agent = 大模型"的误解）。

### 多选题 `[多选]`
考查多要素、边界。2–4 个正确选项。

```
**2.** 下列哪些属于 Agent 的核心组成？（多选）
A. 模型  B. 自主循环  C. 工具  D. 记忆
```
**设计要点**：明确标注"多选"，避免与单选混淆。

### 判断题 `[判断]`
考查易混点，直接针对常见误区。

```
**3.** 上下文窗口越大，模型的表现就一定越好。（  ）
```
**设计要点**：优先选取学习资料"常见误区"节的内容。

### 填空题 `[填空]`
考查关键术语的准确记忆。

```
**4.** 模型一次能处理的最大 token 数称为 ________。
```

### 简答题 `[简答]`
考查机制阐述能力。

```
**5.** 请简述 Agent 的"反思与调整"环节为什么重要。
```

### 连线题 `[连线]`
考查概念与描述的匹配。

```
**6.** 将左侧概念与右侧描述连线：
   提示词  ——————  a. 模型本次能看到的全部信息
   上下文  ——————  b. 跨轮次保存信息的外部机制
   记忆    ——————  c. 用户主动构造的指令
```

### 辨析题 `[辨析]`
考查相邻概念的区分，难度较高。

```
**7.** 小明说："Skill 就是一种提示词模板。"请辨析这个说法。
```

### 应用题 `[应用]`
考查迁移能力，给出新场景要求分析。

```
**8.** 某团队要做一个"自动整理会议纪要并发邮件"的功能。
   请分析：这个功能更适合用工作流还是 Agent？为什么？
```

## 二、难度分级

| 星级 | 层次 | 特征 |
|------|------|------|
| ★ | 识记 | 直接回忆定义、术语 |
| ★★ | 理解 | 需要解释、举例、判断 |
| ★★★ | 应用/分析 | 需要迁移到新场景、辨析差异 |

**配比建议**：★ 约 30%，★★ 约 45%，★★★ 约 25%。

## 三、干扰项设计原则

好的干扰项来自**真实存在的误解**，而非随意编造：

1. **源于误区节**：直接取学习资料"常见误区"中的错误说法
2. **形似而神异**：与正确选项用词相近，但逻辑不同
3. **常见混淆**：取相邻概念的典型特征（如把"记忆"的特征安到"上下文"上）

**避免**：
- ❌ 明显荒谬的选项（送分）
- ❌ 两个选项都对（单选题歧义）
- ❌ 靠文字游戏区分（考语文而非考概念）

## 四、答案与解析写法

每题解析应包含三部分：

1. **为什么对**：解释正确选项的依据
2. **为什么错**：指出干扰项的错误点（单选/多选）
3. **知识点定位**：对应学习资料的哪一节

示例：
```
**1.** B
**解析**：Agent 的本质特征是运行时自主决策（对应"二、核心定义"），
而工作流的步骤由人预先写死。A 项错在速度并非本质区别；
C 项错在联网只是工具的一种，非本质；D 项错在两者通常都依赖大模型。
```
