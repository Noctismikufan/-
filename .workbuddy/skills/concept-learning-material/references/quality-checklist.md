# 学习资料质量检查清单

生成概念学习资料后，逐项核对本清单。任何一项不通过都必须修正后再交付。

## 一、定义质量

| 检查项 | 说明 | 反例 |
|--------|------|------|
| 非循环定义 | 定义中不能出现被定义概念本身或其同义词 | ❌ "Agent 是一种智能体" |
| 可检验 | 定义能用于判断"某物是不是该概念" | ❌ "Agent 是很厉害的东西" |
| 拆解关键词 | 定义中的关键术语要逐个解释 | — |

## 二、内容完整性

- [ ] 说明了"它解决什么问题"（存在的理由）
- [ ] 有工作原理/机制的描述，而非只有结论
- [ ] 至少 1 个**具体**示例（含具体场景、输入输出）
- [ ] 有类比，且**明确说明类比的局限**
- [ ] 列出了常见误区
- [ ] 区分了相邻/易混淆概念
- [ ] 给出了延伸学习方向

## 三、准确性

- [ ] 没有编造事实、数据、引用
- [ ] 不确定的内容已标注（如"存在不同说法"）
- [ ] 术语使用一致，不前后矛盾
- [ ] 时效性内容已说明时间背景

## 四、可读性

- [ ] 术语首次出现有解释（中英对照）
- [ ] 由浅入深，先直觉后严谨
- [ ] 段落简短，多用列表
- [ ] 无长难句堆砌

## 五、风格

- [ ] 无营销式夸张（"革命性""颠覆""史上最强"）
- [ ] 无空洞套话（"众所周知""不言而喻"）
- [ ] 语气客观平实
- [ ] 标点规范，中英文之间空格得当

## 常见反模式（必须避免）

1. **同义反复**：用概念解释概念，读者读完还是不懂
2. **只给结论不给机制**：说了"是什么"，没说"为什么"和"怎么运作"
3. **假类比**：类比很生动但会误导，且不说明局限
4. **伪深度**：堆砌术语显得专业，实际没有解释
5. **无示例**：通篇抽象，读者无法落地
6. **混淆相邻概念**：把 Agent 和 LLM、上下文和提示词混为一谈
7. **过度承诺**：把概念说得无所不能
